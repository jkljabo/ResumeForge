# ResumeForge

ResumeForge is a resume generation platform written in Python.

## Requirements

- Python 3.13+
- Virtual Environment

## Installation

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Build

```powershell
python build_resume.py
```

## Run Tests

```powershell
python -m pytest
```

## Verify Project

```powershell
.\verify-project.ps1
```
